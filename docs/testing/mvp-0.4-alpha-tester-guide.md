# 덜어냄 MVP 0.4-alpha RC2 테스터 가이드

**빌드**: v0.4.0-alpha RC2 · f969396

## 실행 방법

Release 폴더에서 직접 실행:
```
deoreonem_desktop.exe
```

조용한 나무 (가든 오버레이) 별도 실행:
```
deoreonem_desktop.exe --garden
```

## 빌드 확인

앱 실행 후 하단 푸터에 다음이 표시되어야 합니다:
```
v0.4.0-alpha RC2 · f969396
```
이 텍스트가 보이지 않으면 잘못된 빌드를 실행 중입니다.

## 테스트 체크리스트

### 한글 입력 안정성 (P0)
- [ ] 입력 필드에 다음 문구를 빠르게 입력:
  - 걱정이 있어요
  - 괜찮아요
  - 앉아있어요
  - 읽어요
  - 값이 비싸요
  - 프로젝트 걱정이 있어요
- [ ] 받침 + 모음 조합 중 입력이 끊기거나 사라지지 않음
- [ ] 백스페이스 후 계속 입력 시 충돌 없음
- [ ] 여러 줄 입력 후 "분류하기" 정상 동작

### 기본 흐름
- [ ] 앱 실행 → "시작하기" → 텍스트 입력
- [ ] "분류하기" → 각 항목에 카테고리 지정 (내일 / 이번 주 / 걱정만 / 메모)
- [ ] 첫 번째 행동 선택 (또는 건너뛰기)
- [ ] 요약 화면 → "완료하기"
- [ ] 완료 화면 표시

### 세션 간 데이터 보존 (P0)
- [ ] 세션 완료 후 앱 완전 종료
- [ ] 앱 재실행
- [ ] "맡겨둔 것 확인하기" 버튼 표시됨
- [ ] 일정 / 메모 / 감정 서랍 탭에 이전 항목 표시됨
- [ ] 걱정 항목 "이 걱정 내려놓기" 동작
- [ ] 두 번째 세션 생성 → 완료 → 종료 → 재실행 → 리뷰 정상

### 조용한 나무 (가든 오버레이)
- [ ] "조용한 나무 보기" 클릭 → 오버레이 창 열림
- [ ] 오버레이 드래그 이동
- [ ] 오버레이 더블클릭 → 아무 일도 없음 (메인 앱 실행 안 됨)
- [ ] Esc 또는 메뉴 → "조용한 나무 닫기"로 닫기
- [ ] 걱정 내려놓기 후 → 오버레이에 미세한 빛남 효과
- [ ] 메뉴에는 "위치 초기화"와 "조용한 나무 닫기"만 있음

### 중복 실행 방지
- [ ] 메인 앱 실행 중 → exe 다시 실행 → 중복 창 없음
- [ ] "조용한 나무 보기" 빠르게 연타 → 하나만 열림
- [ ] 조용한 나무 열린 상태에서 "조용한 나무 보기" 클릭 → 안내 메시지만

## 알려진 제한 사항

- 인터넷 연결 필수 (API 서버 통신)
- Windows 전용
- 오프라인 모드 없음
- 조용한 나무에서 메인 앱 열기 비활성 (RC2 제한)
- 알림/트레이 아이콘 없음
- 인스톨러 미포함 (Inno Setup 필요 — 추후 제공 예정)

## 버그 리포트 방법

1. **재현 순서**: 어떤 순서로 조작했을 때 문제가 발생하는지
2. **기대 동작**: 어떻게 동작해야 한다고 생각하는지
3. **실제 동작**: 실제로 무엇이 일어났는지
4. **스크린샷**: 가능하면 첨부
5. **launch_diagnostics.log**: `%APPDATA%\ScopeWorks\DeoReoNem\launch_diagnostics.log` 첨부

## 런타임 데이터 위치

```
%APPDATA%\ScopeWorks\DeoReoNem\
```

포함 파일:
- `completed_sessions.json` — 완료된 세션 ID 목록
- `garden_state.json` — 양분 상태
- `main_app.lock` / `garden_overlay.lock` — 중복 실행 방지
- `launch_diagnostics.log` — 실행/세션 완료 기록

## 초기화 방법

모든 로컬 데이터를 초기화하려면:
1. 앱 완전 종료 (조용한 나무 포함)
2. `%APPDATA%\ScopeWorks\DeoReoNem` 폴더 삭제
3. 앱 재시작
